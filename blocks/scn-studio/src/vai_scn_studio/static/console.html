커스텀 사전 — 상품명 · 전문용어

범용 STT는 "무배당 행복플러스보험" 같은 고유명사를 거의 확실히 틀린다. 틀린 인식은 검색과 요약까지 함께 망가뜨리므로 여기서 교정한다.

정답 표기오인식 표기 (쉼표 구분) 분류

검색 튜닝 콘솔

"왜 이 문서가 안 나오지"를 직접 진단한다. Dense(의미)·Sparse(키워드)·리랭킹 중 어디서 밀렸는지가 개선 방향을 정한다.

평가셋 실행

룰·사전·청킹을 바꾼 뒤 좋아졌는지 나빠졌는지를 숫자로 확인하지 못하면 모든 튜닝이 추측이 된다.

팝업 채택률

상담원이 팝업을 실제로 썼는지가 품질 개선의 유일한 객관 신호다. 채택되지 않은 질의가 곧 다음 개선 대상이다.

대화 시뮬레이터 — 배포 없이 흐름 확인

고객사가 시나리오를 직접 늘리려면 “이렇게 말하면 어디로 가는지”를 스스로 볼 수 있어야 한다. 그게 안 되면 결국 공급사에 물어보게 된다. 실제 대화 엔진(BOT-VOICE)을 그대로 부른다 — 시뮬레이터 전용 구현을 두면 “시뮬레이터에서는 되는데 실제로는 안 된다”가 가능해진다.

읽기 미리듣기 — 숫자·금액·전문용어

합성 전에 읽기 텍스트를 본다. 소리를 들어야만 알 수 있으면 사전을 고칠 때마다 전체 합성을 돌려야 한다. “2,000원”이 어떻게 읽히는지, 상품명이 영어로 새는지가 여기서 드러난다.
