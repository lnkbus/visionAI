# VisionAI — B2B AI 상담 플랫폼 (온프레미스 / SaaS 하이브리드)

> 주식회사 링버스(LNKBUS) · B2B 설계/기획 문서 v1.0 · 2026-08

## 프로젝트 개요

**VisionAI**는 금융·보험권을 1차 타겟으로 하는 **B2B AI 상담 플랫폼**입니다.
동일한 코드베이스로 **온프레미스(고객사 설치형)**와 **SaaS(클라우드 구독형)** 두 가지 방식으로
공급하며, 1단계 텍스트/음성 AI 상담을 거쳐 **2단계 AI 가상상담원(아바타 기반 실시간 상담)**으로
확장하는 것을 목표로 합니다.

### 사업 배경

- 링버스는 현대해상 미래아키텍처 수립 컨설팅(기간계 DB 설계, 클라우드 전환방안) 등
  금융권 IT 컨설팅을 수행하며 금융/보험 도메인의 시스템 구조와 규제 환경에 대한 이해를 보유
- 금융권은 망분리·전자금융감독규정 등으로 **온프레미스 수요가 견고**한 동시에,
  중소형 고객(GA, 콜센터 운영사, 핀테크)은 **SaaS 선호** → 하이브리드 공급 모델이 필수
- 컨설팅(용역) 매출 → **솔루션(라이선스/구독) 매출**로의 사업 전환 발판

### 핵심 전략 3줄 요약

1. **One Codebase, Two Deployments** — 쿠버네티스 기반 단일 코드베이스로 SaaS와 온프레미스를 동시 지원
2. **LLM 추상화 게이트웨이** — SaaS는 상용 API(Claude 등), 온프레미스/망분리 환경은 로컬 LLM(vLLM)으로 교체 가능한 구조
3. **상담 파이프라인의 단계적 진화** — 텍스트 챗봇 → 음성 상담 → 아바타 가상상담원까지 동일 코어(대화 엔진 + RAG 지식베이스) 재사용
