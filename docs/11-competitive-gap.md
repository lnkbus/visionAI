# 11. 경쟁 제안서 대비 격차 — 무엇이 없고, 무엇이 더 있는가

> 참고자료: **에스원 AICC 상담자동화 솔루션 구축 제안서** (03. 제안 내용, 16면)
> 이 문서는 그 제안서의 항목을 우리 제품에 하나씩 대 본 결과다.
> **없는 것을 없다고 적는 것이 목적**이다 — 제안서 대응 시 여기가 그대로 리스크다.

## 요약

| | 항목 수 |
|---|---|
| ✅ 대응됨 | 6 |
| ◐ 부분 (API는 있고 화면이 없거나, 반대) | 7 |
| ✗ 없음 | 8 |

**가장 큰 격차는 "화면"이다.** 엔진과 API는 상당 부분 있는데, 경쟁 제안서가
그림으로 보여 주는 **저작·운영 화면**이 우리에겐 대부분 없다. 제안 평가에서
이건 기능 부재와 같은 취급을 받는다.

## 우리에게 있고 제안서에 없는 것

균형을 위해 적어 둔다. 제안 대응에서 차별화 논지가 될 자리다.

| 우리 | 왜 의미 있나 |
|---|---|
| **오프라인 DRM** (H/W 지문, 라이선스 서버 없음, call-home 없음) | 폐쇄망 조달에서 그대로 요구사항이다 |
| **해시 체인 감사 로그** — 변조 탐지 + 끊긴 지점 특정 | 금융권 감사 대응 |
| **블록 단위 판매** — 배포·라이선스·청구가 한 단위 | 단계적 도입과 견적 유연성 |
| **에어갭 반입 계산** (의존 폐포·토픽 생산자 자동) | "이미지 하나 빠져 반입 재승인"을 없앤다 |
| **형상 고정 + 시점 이력** | GS인증 변경 통제, "그때 뭘 납품했나" |
| **품질 회귀 게이트** (골든셋 6종, CER/WER 포함) | 모델을 바꿔도 품질이 조용히 나빠지지 않는다 |
| **블록 인터페이스 시험 콘솔** | `/readyz` 초록인데 못 도는 상태를 잡는다 |
| **개인정보 마스킹이 룰셋과 무관하게 항상 동작** | 룰 편집 실수로 마스킹이 꺼지지 않는다 |

## 다음에 무엇부터 하나

**화면 셋이 가장 싸고 효과가 크다.** 전부 API가 이미 있어 화면만 붙이면 된다.

1. **대화 시뮬레이터** — `scenarios/dry-run` 이 이미 있다
2. **TTS 사전 + 미리듣기 TEST Tool** — `tts/preview` + 전처리가 이미 있다
3. **AI Portal 대시보드 1단계** — 콜 이력 조회·기간별 통계

그 다음이 **시나리오 Life Cycle + Export/Import**다. 이건 데이터 모델부터
필요해 규모가 다르지만, 없으면 "고객사가 자체 확장한다"는 논지를 세울 수 없다.

**학습 도구(Excel 업/다운로드)**는 규모 대비 평가 점수가 높은 항목이다.
`evalctl` 이 이미 골든셋을 다루므로 형식 변환과 화면이면 된다.
